# IPTV playlist (auto-updated, free, cloud-hosted)

Автоматически собранный и проверенный M3U-плейлист + XMLTV EPG для Samsung
Smart TV. Работает на серверах GitHub — компьютер для этого включать не нужно.

- Плейлист: `docs/playlist.m3u`
- EPG: `docs/epg.xml`
- Обновляется каждые 8 часов через GitHub Actions (`.github/workflows/update.yml`)
- Источники — только легальные публичные IPTV-потоки из
  [iptv-org/iptv](https://github.com/iptv-org/iptv), проверенные на живость
  перед каждой публикацией.

Если новая сборка получилась хуже (мало рабочих каналов), автоматика не
публикует её — на сайте остаётся прошлая рабочая версия (это гарантирует
история git: без коммита старые файлы просто продолжают отдаваться).
